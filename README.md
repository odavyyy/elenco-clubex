# 🚪 O elenco dos Portões do Clubex

Página com o **elenco da série animada "Os Portões do Clubex"**, do Instagram [@os_bacanos67](https://www.instagram.com/os_bacanos67/).

🔗 **Ver o elenco:** https://odavyyy.github.io/elenco-clubex/

## O que mostra

- **13 personagens** desenhados até agora, todos na **mesma escala** em que aparecem nos vídeos (quadro vertical 1080×1920).
- Separados por grupo: quem aparece no **Episódio 1**, os **míticos** (Ep 3 ao Ep 7) e as **ameaças** da temporada.
- Um guia de "como ler cada um de longe": a silhueta, o objeto e a cor que identificam cada personagem (a cartola do Homem-Distinto, os tênis sagrados das Uper Fléguis, a corrente do Douradex, as esferas do Pássaro...).
- A lista de quem **ainda falta desenhar**.

Estilo: bonecos 2D em traço chapado com contorno ameixa.

## Tecnologia

Uma página só (`index.html`), com os personagens desenhados em SVG direto no código. Publicada pelo **GitHub Pages**.
